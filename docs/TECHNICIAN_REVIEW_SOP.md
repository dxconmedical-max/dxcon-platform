# Technician Review SOP

1. Open **Lab → Technician queue** (`/app/lab/result-review`).
2. Select pending result; inspect original vs normalized value, flags, reference range.
3. Add technical note when validating.
4. **Validate** only when mapping and specimen context are correct.
5. **Reject** or **rerun** with documented reason for invalid results.
6. Escalate critical values; acknowledge alerts before release can proceed.
7. Do not release reports — doctor approval required.
