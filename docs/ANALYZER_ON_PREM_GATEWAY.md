# Analyzer On-Prem Gateway

Deployment patterns (foundation documentation):

| Pattern | Use case |
|---------|----------|
| On-prem gateway | ASTM/HL7 instruments on lab LAN |
| VPN / private link | Cloud DxCon ↔ hospital network |
| Outbound-only connector | Instruments initiate connection |
| Cloud relay | Managed bridge (not included in this sprint) |
| Serial-to-network gateway | Legacy RS-232 analyzers |

No map or vendor credentials are committed to the repository.
