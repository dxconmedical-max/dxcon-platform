# Doctor Approval SOP

1. Open **Doctor → Clinical review** (`/app/doctor/review`).
2. Review technician-validated results and patient context per permissions.
3. Add clinical interpretation note.
4. **Approve** and electronically sign via reporting approval (audit signature foundation).
5. **Release** is a separate explicit action after approval.
6. Return to technician if technical rework required.
7. Partner doctors see only authorized patients/results.
